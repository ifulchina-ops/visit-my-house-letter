# Visit My House

![The invitation letter](entry.png)

A handwritten-style letter on cream paper, drawn from scratch in Python: a house, a cat by the door, the kettle on, the wifi password on the fridge — and cake.

Run: `python3 main.py` — writes a 1024x1024 `entry.png` to `$MAKEFUN_OUTPUT_DIR` (default `/output`).
